# Apply AI Reply

1. In the chat, copy the AI's **whole reply**, not just one code block, so file paths and ``` fences come along.
2. Run **Send to AI: Apply AI Reply**.
3. Tick the files to write. Existing files are replaced, new ones created.

Every change is one undo step (Ctrl+Z) and shows in git. Files that run on install or open, such as `package.json` or anything under `.github/`, are left unticked so you review them on purpose.
