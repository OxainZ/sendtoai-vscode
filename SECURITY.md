# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **sendtoai** (`oxainz.sendtoai`), please report it privately:

- **Email**: [report via GitHub Security Advisories](https://github.com/OxainZ/sendtoai-vscode/security/advisories/new) — preferred
- **Response window**: best-effort within 7 days
- **Scope**: code in `src/` (bundler, panel, extension entry, cost estimator), build scripts, license enforcement

Please do **not** open a public issue for security reports.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 3.7.x   | ✅ active |
| < 3.7   | ❌ end of life |

## Disclosure

Once a fix is published to the Marketplace, the advisory will be made public with credit (unless anonymity is requested).
